# 👶 Трекер сна Севы — Telegram Mini App & Bot

Полнофункциональное приложение для отслеживания сна ребенка в Telegram с совместным доступом для мамы и папы.

## 🚀 Основные возможности

1. **Таймер сна и бодрствования в 1 клик:**
   - Переключение между режимами «Спит» и «Бодрствует».
   - Автоматический отсчет длительности в реальном времени.
   - Быстрая коррекция времени («Уснул 5/10/15 мин назад»).
   - Ручной ввод и редактирование прошлых снов.

2. **Умный расчет времени укладывания (ВБ — время бодрствования):**
   - Настроено под возраст **2 месяца 7 дней** (норма ВБ: **75–90 минут**, в среднем 80 мин).
   - Учитывает физиологию: первое утреннее ВБ короче, вечернее перед ночью — длиннее.
   - Статусы:
     - 🟢 *Спокойное бодрствование* (> 20 мин)
     - 🟡 *Мостик на сон* (5–20 мин — пора готовиться к укладыванию и ритуалу)
     - 🔵 *Время спать* (0–5 мин)
     - 🔴 *Риск перегула* (если бодрствует дольше нормы)
   - Автоматические напоминания родителям в Telegram перед окончанием ВБ и при риске перегула.

3. **Суточная сводка и аналитика:**
   - Интерактивный **24-часовой таймлайн дня** с цветовой разметкой (ночь / день / бодрствование).
   - Карточки метрик: суммарный сон, дневной сон, ночной сон, среднее время бодрствования.
   - Календарь для просмотра любого дня.

4. **Совместный семейный доступ (Мама + Папа):**
   - Уникальный код семьи (например, `BABY-XXXX`).
   - Синхронизация данных: оба родителя видят единый таймер и историю в реальном времени.
   - Подключение в 1 клик через ссылку `t.me/Sevasleepbot?start=join_КОД`.

## 🛠 Запуск проекта

### 1. Быстрый запуск
```bash
./run.sh
```
или
```bash
source venv/bin/activate
python main.py
```

Сервер запустится на `http://localhost:8000`. Вы можете открыть его в браузере или с телефона в локальной сети (`http://IP_ВАШЕГО_МАКА:8000`).

## 📱 Подключение Telegram Mini App к боту (@Sevasleepbot)

Telegram требует, чтобы WebApp открывался по защищенному протоколу **HTTPS**.

### Вариант 1. Локальный туннель для тестирования на телефоне (через Cloudflare или Ngrok)
1. Запустите туннель:
   ```bash
   npx cloudflared tunnel --url http://localhost:8000
   # или: ngrok http 8000
   ```
2. Скопируйте полученную https-ссылку (например: `https://xxxx.trycloudflare.com`).
3. Вставьте её в файл `.env`:
   ```env
   WEBAPP_URL=https://xxxx.trycloudflare.com
   ```
4. В боте [@BotFather](https://t.me/BotFather):
   - Отправьте команду `/setmenubutton`.
   - Выберите вашего бота `@Sevasleepbot`.
   - Введите ссылку на WebApp.
   - Теперь у всех пользователей слева от поля ввода в Telegram появится кнопка запуска приложения!

### Вариант 2. Быстрое бесплатное развертывание в облаке (24/7)
Код полностью готов для деплоя на любой бесплатный хостинг (Render, Railway, Fly.io, Amvera, TimeWeb Cloud):
- Команда запуска: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- База данных SQLite сохраняется в файл `sleep_tracker.db`.
